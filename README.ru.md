# Ability Draft для Deadlock

[English](README.md) · **Русский**

Серверный плагин [Deadworks](https://github.com/Deadworks-net/deadworks). Каждый игрок набирает четыре способности
других героев на экране драфта Street Brawl, после чего лобби играет Standard или Street Brawl с этими наборами.

Клиент игры не модифицируется. Всё работает на вашем сервере; игроки заходят через `connect` и ничего не ставят.

![Родной экран драфта с карточками способностей](showcase/native-draft-1-of-4.png)

## Как проходит игра
1. Хост запускает сервер. Игроки открывают консоль Deadlock, пишут `connect <ip>:27067` и выбирают героев
   (обычным способом или командами `/hero haze`, `/team amber|sapphire` в чате).
2. Хост (первый зашедший игрок) пишет в чат **`/draft`** (или `dw_draft` в консоли).
3. Голосование за правила: в чат **1** — Standard, **2** — Street Brawl. 25 секунд; при ничьей решает голос хоста,
   иначе Standard.
4. Матч стартует, и открывается **родной экран драфта Street Brawl с карточками способностей**. Четыре выбора,
   последний — ульта, на каждый выбор три «прокрутки» штатной кнопкой.
   **Карточку берут цифрой в чате: Enter → `1`, `2` или `3` → Enter (левая, верхняя, правая). Сообщение никому не
   показывается. Кликать по карточке способности мышью нельзя — игра вылетит.**
5. Street Brawl: после четвёртой способности тот же экран переходит к обычным предметам, дальше матч идёт как
   Street Brawl.
   Standard: как только все набрали по четыре способности (или через 50 секунд — остальное добирается случайно),
   карта перезагружается в обычный матч, и плагин возвращает каждому команду, героя и набор.
6. `/newdraft` (хост) возвращает всех в лобби.

Если родной экран недоступен — после патча игры плагин может не найти нужные функции, см.
[PATCHING.ru.md](PATCHING.ru.md), — драфт идёт запасным способом, текстовым меню перед прицелом до старта матча:
`1`-`3` берёт карточку, `R` + `1`-`3` заменяет её. `/lang en` переключает названия способностей на английский
(по умолчанию русский).

## Установка (только хост)
Только Windows: у Deadworks нет сборки под Linux, потому что Valve не выпускает Linux-сервер Deadlock.

1. Deadlock из Steam (или отдельная копия через SteamCMD, приложение `1422450`).
2. [.NET 10](https://dotnet.microsoft.com/download/dotnet/10.0).
3. Свежий [релиз Deadworks](https://github.com/Deadworks-net/deadworks/releases), распакованный в папку Deadlock.
4. Архив из [релизов](../../releases) этого репозитория, распакованный в ту же папку Deadlock.
5. Запустить `game\bin\win64\start-abilitydraft.bat`.

Сам хост заходит так: консоль (`` ` ``) → `connect localhost:27067`.

**Друзьям не из вашей сети проброс портов не нужен.** При старте плагин включает вход через Steam и печатает
команду для него в лог сервера (`STEAM CONNECT: connect [A:1:…]`); хосту она также приходит в чат при входе,
а `/id` показывает её снова. Друзья вставляют эту строку в консоль целиком, вместе со скобками. Идентификатор
меняется при каждом запуске сервера. Вход по адресу тоже работает: пробросьте на роутере UDP/TCP 27067 и
используйте `connect <ip>:27067`. Запуск сервера с `-ad_nosteamconnect` оставляет вход через Steam выключенным.

Серверу и игре на одной машине нужно много памяти. На 8 ГБ всё работает, но загрузка карты занимает около минуты,
и столько же — перезагрузка в Standard.

### Сборка из исходников
```
dotnet build AbilityDraft -c Release
pip install capstone
python tools\find_sigs.py
```
Сборка сама копирует плагин в `game/bin/win64/managed/plugins`; `find_sigs.py` кладёт рядом файл сигнатур.
Если Steam стоит не в `C:\Program Files (x86)\Steam`, добавьте к сборке `-p:DeadlockDir="<папка Deadlock>"` и
передайте эту папку скрипту. Запуск сервера: `tools\host.ps1` (или `tools\host.ps1 -Lan`).

## После патча игры
Deadworks перестаёт запускаться, пока не выйдет его обновление, а сигнатуры плагина может понадобиться
сгенерировать заново. В [PATCHING.ru.md](PATCHING.ru.md) расписано, что проверять и в каком порядке.

## Известные ограничения
- **Клик по карточке способности роняет клиент.** Родной экран считает каждую карточку предметом; у способности
  данных предмета нет, и клиент читает чужую память. Поэтому выбор идёт через чат.
- **В заголовке по-прежнему «Выбор предметов».** Этот текст лежит в переводе на клиенте, сервер его не меняет.
- **Меню прокачки по TAB показывает родные способности героя.** Прокачка набранных работает; состав ячеек меню
  берётся из данных героя на клиенте.
- **В Standard на все четыре выбора 50 секунд**, потому что драфт занимает первую фазу покупки Street Brawl.
- Проверено на одном игроке с ботами. Полное лобби и матч до конца не проверялись, а из 152 способностей на чужом
  герое кастовалось лишь несколько.

## Что внутри
- `AbilityDraft/` — плагин (C#): `DraftPlugin.cs` (фазы, голосование, текстовый драфт), `NativeDraft.cs` (драфт на
  родном экране, переход в Standard), `Native.cs` (функции игры, найденные по сигнатурам), `Match.cs`, `Lobby.cs`,
  `Ui.cs`, `Debug.cs` (лог и тестовый мост через файл), `AbilityPool.g.cs` (имена способностей, генерируется).
- `tools/` — скрипты запуска сервера, генератор пула способностей, поиск сигнатур, сборка релиза, чтение дампов.
- `showcase/` — клип и скриншоты.

Файлов игры в репозитории нет. Мод сделан с помощью ИИ (Claude Code + universal-modder).
Используйте только на своих серверах; на официальные серверы Valve это никак не влияет.
